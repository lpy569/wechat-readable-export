# 排错说明

## 找不到账号目录

先检查微信的实际数据存储路径，再提供 `--data-dir`。程序需要 `xwechat_files` 下包含 `db_storage` 的账号目录；旧版 `WeChat Files`、手机备份包或压缩文件不是这个读取器的输入。

多个账号需要 `--account`；账号参数填写账号**目录名称**，不是昵称。传具体账号目录时可以省略 `--account`。

## 未找到微信进程 / 无法读取进程

先在电脑上自行完成微信登录。程序不操作登录界面。请使用 64 位 Python；可以通过 `python -c "import struct; print(struct.calcsize('P') * 8)"` 检查。

微信与 Python 权限不一致可能导致只读访问被拒绝。建议两者均以普通用户方式运行。若组织策略禁止进程读取，使用组织允许的备份方式；无需关闭防护或修改系统安全设置。

## 所需数据库密钥不可用

保持微信运行，打开目标会话后重试。如果仍失败，请记录微信和 Python 版本。微信版本变动可能改变内存配置对象布局；仅首页或后续页校验通过的材料才会使用，程序不会把失败结果当作成功导出。

## 快照 / WAL 校验失败

微信可能正在写入或 checkpoint。等待当前同步和文件接收完成后重试。程序不会为获得静态副本而自动退出微信，也不会用缺少最新提交的旧快照掩盖错误。

## 同名联系人 / 未知发送者 / 未知消息

先运行 `contacts --search "名称"`，再用 `export --contact-id "唯一ID"`。不要通过昵称猜测账号。

未映射发送者、无法解析的消息或重复服务器 ID 会在输出提示中保留。遇到提示时，检查 JSON 的来源分片和身份状态；它们不会被自动删除或补造。

## 导出文件已存在

换一个输出目录，或在确定可以替换时使用 `--overwrite`。默认行为保护已有结果。

## 程序被强制终止后有临时文件

正常退出、Python 异常和 Ctrl+C 会尝试清理本次临时解密文件。任务管理器强制终止、系统崩溃或断电无法保证执行清理。临时目录使用 `wechat-readable-export-` 前缀；确认没有导出任务运行后，可在系统临时目录中人工删除遗留的同前缀目录。不要删除微信原始数据目录。

## HTML 打开后没有图片或无法播放语音

v0.1.0 导出可读文字与媒体标记，不包含媒体原文件。浏览器中的搜索和筛选均在本地执行；可用浏览器打印功能另存 PDF。
