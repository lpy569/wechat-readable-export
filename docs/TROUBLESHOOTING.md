# 排错说明

## 找不到账号目录

先检查微信的实际数据存储路径，再提供 `--data-dir`。程序需要 `xwechat_files` 下包含 `db_storage` 的账号目录；旧版 `WeChat Files`、手机备份包或压缩文件不是这个读取器的输入。

多个账号需要 `--account`；账号参数填写账号**目录名称**，不是昵称。传具体账号目录时可以省略 `--account`。

## 未找到微信进程 / 无法读取进程

先在电脑上自行完成微信登录。程序不操作登录界面。请使用 64 位 Python；可以通过 `python -c "import struct; print(struct.calcsize('P') * 8)"` 检查。

微信与 Python 权限不一致可能导致只读访问被拒绝。建议两者均以普通用户方式运行。若组织策略禁止进程读取，使用组织允许的备份方式；无需关闭防护或修改系统安全设置。

## 所需数据库密钥不可用

保持微信运行，打开目标会话后重试。如果仍失败，请记录微信和 Python 版本。微信版本变动可能改变内存配置对象布局；仅首页或后续页校验通过的材料才会使用，程序不会把失败结果当作成功导出。

## 快照 / WAL 校验失败

微信可能正在写入或 checkpoint。等待当前同步和文件接收完成后重试。程序不会为获得静态副本而自动退出微信，也不会用缺少最新提交的旧快照掩盖错误。

## 同名联系人 / 未知发送者 / 未知消息

先运行 `contacts --search "名称"`，再用 `export --contact-id "唯一ID"`。不要通过昵称猜测账号。

未映射发送者、无法解析的消息或重复服务器 ID 会在输出提示中保留。遇到提示时，检查 JSON 的来源分片和身份状态；它们不会被自动删除或补造。

## 导出文件已存在

换一个输出目录，或在确定可以替换时使用 `--overwrite`。默认行为保护已有结果。

## 程序被强制终止后有临时文件

正常退出、Python 异常和 Ctrl+C 会尝试清理本次临时解密文件。任务管理器强制终止、系统崩溃或断电无法保证执行清理。数据库临时目录使用 `wechat-readable-export-` 前缀，高清图片解码临时目录使用 `wechat-image-` 前缀，语音解码临时目录使用 `wechat-voice-` 前缀；确认没有导出任务运行后，可在系统临时目录中人工删除遗留的同前缀目录。不要删除微信原始数据目录。

## HTML 打开后没有图片或无法播放语音

v0.2.0 会显示可以定位和解码的本地图片与表情；查看占位文字旁的原因，以及 JSON 中的 `media`、`media_statistics` 和 `media_resource_status`。可以先在微信中打开目标图片，等待本地加载完成，再重新导出。图片密钥只扫描一次；未获得时可在微信打开大图后重试。微信 wxgf/HEVC 图片使用本地 FFmpeg 解码；安装项目依赖会同时安装 `imageio-ffmpeg` 提供解码程序，也可以使用 PATH 中已有的 FFmpeg。解码失败时，若本地存在匹配缩略图会显示缩略图，并明确标注。旧导出只有缩略图时，需要重新读取本地媒体才能提高分辨率，单独转换 JSON 不会增加图片细节。

自定义表情的本地缓存布局因版本而异，不能保证全部恢复；可在导出时添加 `--download-stickers` 尝试从微信 CDN 获取。此参数才会允许相关网络请求，地址过期、内容加密、校验失败时仍显示原因。

`[捂脸]`、`[微笑]` 等是文字消息里的内置表情标签，使用独立的本地 PNG 素材缓存或 JSON 内嵌素材进行 HTML 渲染。Windows 缓存路径为 `%LOCALAPPDATA%\wechat-readable-export\native-emoji-v1.json`。缺少素材的标签会继续显示文字；已有素材时重新执行 `convert` 即可更新 HTML，无需重新读取微信。TXT 和 JSON 的消息正文仍保留标签以免改变原文，HTML 搜索也能匹配原标签。普通 Unicode emoji 会原样显示。

旧版仅含占位文字的 JSON 无法重新恢复图片，需要从微信重新导出。只需要原来的文字导出方式，可以使用 `--no-media`。

语音恢复需要本机保存对应的 `media_*.db` 记录，并安装项目依赖中的 `silk-python`。已有旧导出只显示 `[语音]` 时，需要从微信重新读取本地音频；单独转换旧 JSON 无法补回声音。语音已恢复后会在 HTML 显示播放控件，音频直接嵌入文件，离线也能播放。查看 JSON 中的 `voice_statistics` 和 `voice_resource_status` 可区分未找到本地数据、数据库无法读取和解码失败。可以先在微信播放对应语音后重新导出；超过 8 MiB 或 120 秒的音频会保留原因提示，不截断导出。

视频和附件仍只保留文字标记，不支持在 HTML 中播放。浏览器中的搜索和筛选均在本地执行；可用浏览器打印功能另存 PDF。
